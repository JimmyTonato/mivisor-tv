# MiVisor TV · Entrega 4l: Biblioteca al día en minutos

La 4k está en `docs/entregas/4k.md`. Se mantiene todo.

Gold publica cambios al menos cada 30 min. Antes la app miraba cada 45 min; ahora:

| Qué | Cómo |
| --- | --- |
| «Ping» cada 3 min | Con la app abierta se pide `manifest.json` con su ETag (`If-None-Match`). Sin cambios, GitHub responde 304 sin cuerpo: no se baja nada |
| Hay revisión nueva | Se usa ese mismo manifest (no se pide dos veces) y se baja solo `cambios.enc`. Se cambian solo los canales y categorías afectados; el resto son los mismos objetos y la pantalla no los repinta (ya estaba desde la 4f) |
| GitHub aún sirve el fichero viejo | No se guarda el ETag, así que el siguiente ping lo vuelve a intentar |
| Falla un ID de la Biblioteca al reproducir | Se mira el manifest al momento (como mucho una vez cada 30 s), por si Gold ya cambió esa fuente |
| Al volver a la app | Se mira si hace más de 90 s de la última vez |

Nada con la app cerrada. Coste: un 304 vacío cada 3 min; con cambios, solo las líneas cambiadas.

Retraso máximo con la app abierta: unos 3 min desde que Gold publica. Un aviso instantáneo de verdad (push) necesitaría
que el servidor avisara a la app (por ejemplo Firebase), y eso es tocar el servidor: no se ha hecho.
